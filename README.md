# 狗哥智慧輸入法

macOS 注音輸入法，支援整句組字、中英混打、自動完成、符號與自訂詞彙。需要 macOS 11 以上。

這裡只提供安裝檔，請到 [Releases](../../releases/latest) 下載最新版本。

## 安裝

1. 下載 `狗哥智慧輸入法-macOS.dmg`。
2. 核對檔案沒有被改過：打開「終端機」，輸入

   ```sh
   shasum -a 256 ~/Downloads/狗哥智慧輸入法-macOS.dmg
   ```

   把顯示的值和該版 Release 附的 `SHA256SUMS.txt` 逐字比對，完全相同才安裝。
3. 打開 DMG，雙擊「安裝狗哥智慧輸入法」，依畫面指示完成安裝。
4. 如果輸入法沒有出現，到「系統設定 → 鍵盤 → 文字輸入 → 編輯…」，按「＋」→ 繁體中文 → 狗哥智慧輸入法 → 加入。還是找不到的話，登出再登入一次。

安裝檔尚未使用 Developer ID 簽署及 Apple 公證。第一次打開被 macOS 擋下時，請先完成上面的比對，再到「系統設定 → 隱私權與安全性」允許打開。

## 解除安裝

從 `/Library/Input Methods` 移除「狗哥智慧輸入法.app」，然後登出再登入。
