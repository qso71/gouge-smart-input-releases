全部功能

常用的小事，都幫你想好了。

從聊天、寫文件到寫程式，這些功能都內建在狗哥裡。完整說明在輸入法選單的「狗哥手冊」，每個功能都附試打框。

打字

用注音打 Emoji

打「開心」，候選字接著出現 😊、🧋、🎂。

錯字建議

按錯鍵、聲調或ㄣㄥ不分時，按 Tab 修正，例如把「民天」修成「明天」。

空白鍵就是一聲

ㄒㄧ、空白、ㄢ、空白是「西安」，ㄒㄧㄢ、空白是「先」。

Shift 開頭打英文

按住 Shift 打第一個字母就開始英文單字；單按 Shift 切換中文與純英文。

改句子中間的字

用 ← → 移到某個字前面，再按空白就能換字。

符號與文字範本

連按兩次 ~ 打開符號清單，再按空白就是文字範本。

寫程式

指令提示

在終端機打 git，列出常用指令。指令庫內建 Python、Xcode、ssh、ffmpeg 等指令包，也能下載匯入。

幫你寫 commit

打 -m 加引號再打 f，建議 feat: 和 fix:。

每個 App 記住中英

LINE 是中文、終端機是英文，切過去自動換好。

你的詞庫

個人詞庫

加入常用詞和專有名詞，也可以隱藏、匯入、匯出。

把詞加進詞庫

打字時用 Shift 加 ← → 圈選兩個字以上，按 Return 加入。

記住你的習慣

選過的字下次排第一，打得越久越順手。

iCloud 同步

兩台 Mac 共用詞庫，要你自己打開，詞庫放在你自己的 iCloud。

其他

查字典

選取文字，連按兩次 Control，用「字典」查詢。

狗哥週報

這週打了幾個字、最常打的詞，還有專屬稱號，可以存成圖片分享。

自動更新

有新版會先下載好並通知你，輸入密碼就裝好，更新前會自動備份詞庫。

當機回報

萬一當掉，選單會提醒你，內容看過再自己決定送不送。
